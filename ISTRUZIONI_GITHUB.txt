COME AGGIORNARE:
1. Apri https://github.com/angelotiballi/Portfolio
2. Clicca Add file > Upload files.
3. Apri sul computer la cartella estratta da questo ZIP.
4. Trascina TUTTI i file della cartella sul caricamento (non lo ZIP).
5. GitHub riconoscerà i file con lo stesso nome: conferma Commit changes.
6. Attendi che GitHub Pages aggiorni il sito; apri https://angelotiballi.github.io/Portfolio/ e premi Ctrl+F5.
7. Apri un progetto; nella pagina cerca la sezione Fotografie e video e prova entrambi i collegamenti.

Se nel caricamento GitHub compare un errore di conflitto, torna alla pagina del repository e ricarica.
Non pubblicare documenti riservati, disegni di cantiere o foto non autorizzate.
